# 📚 E-commerce Book Store API

FastAPI-ზე აგებული სრული REST API წიგნების ონლაინ მაღაზიისთვის. პროექტი მოიცავს მომხმარებლების ავტორიზაციას, წიგნების მართვას (სურათების ატვირთვით), კალათას, შეკვეთებსა და ავტომატიზებულ ტესტებს (Pytest).

---

## 🚀 ტექნოლოგიური სტეკი

* **Framework:** FastAPI
* **Database & ORM:** SQLAlchemy, SQLite
* **Authentication:** JWT Tokens (OAuth2), Password Hashing (`bcrypt` / `pwdlib`)
* **Validation:** Pydantic V2
* **Testing:** Pytest, HTTPX

---

## 🛠️ ფუნქციონალი (Features)

* **მომხმარებლები (`/users`):**
  * რეგისტრაცია და ავტორიზაცია (JWT Access Token)
  * პაროლების უსაფრთხო ჰაშირება
* **წიგნები (`/books`):**
  * CRUD ოპერაციები
  * ფაილების/სურათების ატვირთვა (`UUID` იდენტიფიკატორებით)
* **კალათა (`/cart`):**
  * წიგნების დამატება, რაოდენობის მართვა და წაშლა
* **შეკვეთები (`/orders`):**
  * კალათაში არსებული ნივთების შეკვეთად (Checkout) გადაქცევა
* **ტესტირება (`Pytest`):**
  * ავტომატიზებული ტესტები ყველა ძირითადი ენდპოინტისთვის
